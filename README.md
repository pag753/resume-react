# Resume React

Frontend for Pablo de Jesus' resume.

## Scripts

- `npm start`: runs the app locally. API calls are proxied to `http://localhost:3111`.
- `npm run build`: creates the production build.
- `npm run test:ci`: runs tests once.
- `npm run lint`: runs ESLint.

The visual resume styles live in `src/styles/pillar-*.css`. The code changes should keep those files untouched unless the resume design is intentionally being changed.
